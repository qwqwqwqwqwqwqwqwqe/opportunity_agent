## 3. 依次实施的修复方案

### 第一步：补齐诊断与失败复现

- 为身份失败拆分原因：引用缺失、引用未定位、名称对齐未解决、明确项目冲突、作用域不明确、学位冲突、Home Unit 冲突。
- 拒绝诊断增加目标身份、提取身份、`program_quote`、正文块 ID、失败检查项和验证器版本；公开界面只展示安全、限长的信息。
- 保留旧错误码的历史展示兼容，但新决策不再仅依靠 `PROGRAM_MISMATCH`。
- 保存 CMU 两个页面和 GT 两个页面的离线 Fixture；历史拒绝输出缺失的部分使用明确标注的构造响应，不伪称完整历史重放。

### 第二步：统一学校范围内的身份对齐

- 将“项目主体名称、学位、Home Unit”分开比较；学位表达和通用名称后缀仅做格式归一化，不能把 Computer Science 与 Computational Science and Engineering 合并。
- 移除对特定标题分隔符、大小写和标题顺序的依赖。
- 新增结构化 `ProgramIdentityClaim`：官方名称、别名、学位、Home Unit，以及各项原文引用。由现有提取模型在同一次多字段提取中输出，不新增常规模型调用。
- 别名关系必须由当前学校的官方标题、正文或结构关联支持；缩写首字母相同、官网域名相同不能单独证明项目相同。
- 页面匹配器负责候选排序；经验证的身份关联负责字段接受、合并及持久化。generic 页面允许继续分析，但不能直接被当作已验证事实。

### 第三步：改为事实级证据作用域

- 保留标题层级、段落、列表项、表格行及其位置；允许身份引用来自标题或关联段落，字段引用仍必须定位在实际正文中。
- 每条事实增加身份引用和适用范围引用；程序生成定位结果，不信任模型自报位置。
- 对 MS/PhD 比较句，验证事实所对应的范围片段，不再因为外围段落提及另一学位就全部拒绝。
- 同页不同项目、不同学位、不同 Home Unit 分开验证；无法明确绑定的事实保持未知，不借用兄弟栏目身份。
- 保留学校、明确项目冲突、学位、Home Unit、年份、来源安全及字段值验证。无年份日期保留为“年份未确认”，不自动补今年，也不计为已核实的目标申请季日期。

### 第四步：分组汇总，并隔离缓存与入库

- 按“学校、项目主体、学位、Home Unit、申请季”生成作用域身份键；验证后分组产生多个 `ProgramResult`，不再因页面包含多个合法身份而清空全部结果。
- 用户未指定学位或 Home Unit 时，按已确认范围分组展示；要求唯一日期或必须选择一个范围才能完成筛选时才请求澄清。
- 同步更新跨轮合并、缺失任务排除集合、持久化查询和缓存回读；未知范围不能覆盖已确认范围。
- 增加下一版本迁移 `0009`，为项目目录补充学位和 Home Unit，并扩展唯一约束。旧记录保持原样、默认范围未知，不自动推断或删除数据。
- 提取及验证版本升级以隔离旧缓存；旧事实未经新版作用域验证，不得满足具体学位或 Home Unit 的成功标准。新增契约字段提供默认值，旧 A2A 消息仍可读取。

### 第五步：按失败类型执行有界修复

- 明确跨项目、跨学校、跨学位冲突：换合法候选，不重试接受原事实。
- 身份引用不足或名称绑定未解决：先利用已读取页面重建身份上下文；仍无法解决时，允许一次针对缺失绑定的结构化修正。
- 同页修正与已有 Schema 纠错共享一次额外调用配额；记录工具账本、耗时和预算，不允许原样重复调用。
- 保留已验证字段，仅补缺失项；没有新证据或预算耗尽时返回 PARTIAL，不清空旧结果。
- 前端区分“模型输出格式失败”“身份证据不足”“明确范围冲突”“年份未确认”，不再全部展示为 LLM 提取失败。

## 4. 测试与验收

- **CMU 标题泛化**：两个官网页面、不同标题分隔符及标题顺序均能绑定同一有证据支持的项目，不依赖 `MSAII` 必须出现在标题前半段。
- **GT 项目隔离**：MSCS 页面事实不能归入 CSE；正确 CSE 页面能提取并分别绑定硕士、博士及 Home Unit。
- **作用域验证**：同句比较 MS/PhD、同页多项目、共享要求、相邻身份段落、表格行均有正反例；明确交叉归因仍被拒绝。
- **时间范围**：无年份日期保留但不推断年份；明确错误申请季和过期日期继续拒绝。
- **汇总与持久化**：跨轮旧结果保留；不同学位或 Home Unit 不合并；数据库迁移、重复写入、缓存回读和旧契约兼容通过测试。
- **修复预算**：同页最多一次额外修正；修正失败保留已有结果；技术失败不伪装成要求用户提供官网事实。
- **指标报告**：在固定离线 Fixture 上比较修复前后的字段正确率、覆盖率、身份误拒绝率和跨项目污染率；另行报告真实模型成功率、调用次数及提取耗时，不把构造响应测试当作模型准确率。

交付验收要求：上述已确认误拒绝用例通过，跨项目污染负例全部拒绝；正确页面中的有效事实不再因标题格式或外围学位词被整批丢弃。

## 5. 默认边界

- 不更换 Agent 框架，不新增评估 Agent 或在线 Answer Validator，不开展 Crawl。
- 正常页面继续一次批量提取；沿用现有快速提取模型，不因本次修复统一升级昂贵模型。
- 不迁移 `data/conversations.json`，不覆盖现有用户改动。
- 本次先修订计划；代码修改、数据库迁移和部署属于后续实施。
